# Verilog HDL Based Two-Way Traffic Light Controller

## Project Description
A two-way traffic light controller designed using Verilog HDL and Finite State Machine (FSM).

## Files
- traffic_light.v - Main design code
- traffic_light_tb.v - Testbench code

## Tools Used
- Verilog HDL
- GitHub
- Icarus Verilog
- GTKWave

## Objective
To control traffic signals for two roads using an FSM.
Working Principle

The traffic light controller uses a Finite State Machine (FSM) to control traffic signals for two roads.

FSM States

- State 00 – Road 1 Green
- State 01 – Road 1 Yellow
- State 10 – Road 2 Green
- State 11 – Road 2 Yellow

Simulation

The design is verified using a Verilog testbench.

Applications

- Automatic traffic signal control
- Smart traffic management
- Digital system design
