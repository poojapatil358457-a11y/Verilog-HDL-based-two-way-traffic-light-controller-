# Verilog HDL Based Two-Way Traffic Light Controller

## Project Description
A two-way traffic light controller designed using Verilog HDL and Finite State Machine (FSM).

## Files
- traffic_light.v - Main design code
- traffic_light_tb.v - Testbench code

## Tools Used
- Verilog HDL
- GitHub
- Icarus Verilog
- GTKWave

## Objective
To control traffic signals for two roads using an FSM.
